## How a rule flows

`LC.apply(s, action)` copies the state and runs the action as a job. Jobs that need a decision
throw an Ask: the partly-resolved state is kept for display (`s.ask`), and the answer re-runs the
job from a snapshot with all answers so far. After every job `settle()` runs the game state check
(CR 1.8), resolves the bag (CR 7.7, the active player orders their triggers), then the next queued
job (turn steps, challenge damage). Card scripts only touch the game through ctx doors
(`x.damage`, `x.banish`, `x.chooseOne`, `x.buff` …).
