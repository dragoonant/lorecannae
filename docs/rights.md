# Rights

Recorded 2026-10-24, before engine code (`kb/CROSS-PROJECT-LESSONS.md` section 4.2). The decision
this feeds is PLAN D6 (public GitHub Pages). Deployment status lives in `PLAN.md` only.

## Rights holders

| Holder | Owns |
|---|---|
| The Walt Disney Company (Disney, Disney/Pixar) | The characters, their names and designs, and the Disney Lorcana brand and trademark |
| Ravensburger | The game itself (Disney Lorcana TCG), published under licence from Disney |

Card names and rules text belong to them. This project reproduces them as game data.

## Findings

### Ravensburger fan-content policy: not read

- Ravensburger's Disney Lorcana Media Guide has a fan-content policy at
  https://brand.ravensburger-group.com/d/e1vhRSQ7WeNy/overview#/policies/fan-content
- The page sits behind a terms-acceptance dialog. **That dialog was not accepted, so the policy
  text was not read.** Nothing in this project relies on what the policy says.
- What was visible without accepting it: materials may not be used to imply endorsement, and
  logos and trade dress may not be imitated. This project follows both (see below).
- **Owner to read the policy and record its terms here**, including any disclaimer wording it
  prescribes and whether it covers a rules-enforcing client. Tracked in `TODO.md`.

### Pixelborn (precedent: shut down)

- Pixelborn was a fan-made Lorcana simulator. Disney asked it to stop and it went offline in June
  2024.
- Reported features that mattered: it used official card images, it implied affiliation, and it
  hosted prize tournaments.
- Source: wargamer.com/disney-lorcana/pixelborn-shut-down (secondary reporting; not a Disney
  statement).

### Duels.ink (precedent: running)

- Duels.ink operates as a free unofficial Lorcana simulator. Its about page
  (duels.ink/about) says it is built under Ravensburger's Fan Content Policy.
- That is the site's own statement. It is not confirmation from Ravensburger, and it does not tell
  us what the policy says (see above).

### Disney, general fan-game policy

- Marvel and Disney publish no general fan-game policy. Searched in earlier projects on this
  machine (2026-09-23), found none. Not searched again for this project beyond the Ravensburger
  page above.

## Where this project sits

A public, non-commercial fan reproduction of a licensed trading card game, using the real card
names and printed rules text.

- Real card names and rules text: yes, from one generated file (`data/cards.js`).
- Official card images, logos, set symbols, frames, icons, trade dress, audio: none.
- Art: original, generated locally, painted as original archetypes. No prompt names a character,
  franchise, studio, film or artist.
- Nothing sold, no donations, no prize play, no events.
- Labelled unofficial and not affiliated, in `NOTICE.md`, the README and on the title screen.
- Takedown steps are written as commands in `docs/takedown.md` and are carried out without
  argument if either holder asks.

Plainly: tolerance is not permission, and it can be withdrawn at any time. No fair-use argument
is relied on and none is claimed. A fan simulator that copies a publisher's rules text and card
names may be something the holders object to whatever its other features, and Pixelborn is the
reminder. The owner has decided on public Pages (PLAN D6) knowing this. The project is removed
on request.
